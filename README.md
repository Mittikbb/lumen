# Lumen

Живой остров в верхней части рабочего стола Windows 10/11, вдохновлённый Dynamic Island.
Тёмная капсула с мягким свечением тянется к курсору, разворачивается при наведении
и собирает под рукой музыку, буфер обмена и быстрый поиск.

> Статус: ранняя разработка (v0.1).

## Возможности

- [x] Прозрачное окно поверх всех окон, клики мимо острова проходят насквозь
- [x] Свечение и «жидкая» реакция на курсор
- [x] Разворачивание при наведении
- [x] Медиа: текущий трек, обложка, управление (через Windows SMTC)
  - свечение в цвет обложки и в такт музыке, живой эквалайзер
  - анимация смены трека
- [x] История буфера обмена: текст и картинки, закрепление, вставка по клику
  - пароли из менеджеров паролей не сохраняются
- [x] Лаунчер по Alt+Space: программы, калькулятор, перевод величин, поиск в Chrome
- [x] Быстрый запуск установленного ИИ-приложения (Claude, ChatGPT, Gemini или Copilot)
- [x] Установщик и автозапуск вместе с Windows
- [x] Полка для файлов: перетащи файл на остров, потом вытащи его в любое приложение
  - превью картинок, видео и PDF, открытие по клику, «Показать в папке»
- [ ] Погода, скриншоты и OCR

## Установка

Скачай `Lumen_x.y.z_x64-setup.exe` и запусти. Права администратора не нужны.
После установки Lumen запускается вместе с Windows; отключить это можно в меню
иконки в трее («Запускать вместе с Windows»). Там же пункт «Выход».

> Alt+Space по умолчанию занят PowerToys Run, если он установлен. Отключи его
> в настройках PowerToys, и Lumen подхватит сочетание сам.

## Стек

[Tauri 2](https://tauri.app) (Rust) + React + TypeScript + [Motion](https://motion.dev).

## Разработка

Нужны [Node.js](https://nodejs.org), [Rust](https://rustup.rs) и Visual Studio Build Tools
с компонентом «Разработка классических приложений на C++».

```bash
npm install
npm run tauri dev
```

Сборка установщика (появится в `src-tauri/target/release/bundle/nsis/`):

```bash
npm run tauri build
```

Только интерфейс в браузере (без Rust): `npm run dev` и открыть http://localhost:1420.
