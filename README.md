# Lumen

Живой остров в верхней части рабочего стола Windows 10/11, вдохновлённый Dynamic Island.
Тёмная капсула с мягким свечением тянется к курсору, разворачивается при наведении
и собирает под рукой музыку, звонки, буфер обмена, файлы и быстрый поиск.

> Версия 0.4.1 · активная разработка

## Возможности

### Остров
- Прозрачное окно поверх всех окон: клики мимо острова проходят насквозь, фокус он не забирает
- Свечение, «жидкая» реакция на курсор, разворачивание при наведении
- Прячется в полноэкранных играх и видео, можно выбрать монитор

### Музыка
- Текущий трек, обложка и управление для любого плеера (через Windows SMTC):
  Spotify, Яндекс Музыка, браузеры, Telegram и AyuGram
- Свечение в цвет обложки и в такт музыке, живой эквалайзер, анимация смены трека

### Discord
- Звонок на острове: кто в голосовом канале, кто говорит, кнопки микрофона, звука и выхода
- Статус «Слушает» в профиле для любого плеера (Spotify Discord показывает сам)

### Инструменты
- Поиск по Alt+Space: программы, калькулятор, перевод величин, поиск в интернете
  и быстрый вопрос установленному ИИ-приложению (Claude, ChatGPT, Gemini или Copilot)
- Скриншот области (Alt+Shift+S) и текст с экрана (Alt+Shift+T, встроенный OCR Windows)
- История буфера обмена: текст и картинки, закрепление, вставка по клику;
  пароли из менеджеров паролей не сохраняются
- Полка для файлов: перетащи файл на остров, потом вытащи его в любое приложение;
  превью картинок, видео и PDF
- Погода от [Open-Meteo](https://open-meteo.com) без ключей: прогноз на неделю,
  температура в свёрнутом острове, предупреждение «через час дождь»

### Настройки
Открываются из меню в трее, шестерёнкой на развёрнутом острове или повторным запуском
Lumen из меню «Пуск». Всё применяется сразу:

- **Остров** — размеры, скругление, отступ, монитор, задержки, притяжение к курсору,
  что показывать в покое (часы, дата, погода, трек), уведомления
- **Внешний вид** — пресеты, сила и цвет свечения, реакция на музыку, скорость
  и упругость анимаций, режим без анимаций
- **Клавиши** — любые сочетания для поиска, скриншота и распознавания текста
- **Модули** — размер и срок хранения истории буфера, приложения-исключения, лимит полки,
  поисковик (Google, Яндекс, DuckDuckGo, Bing)
- **Общие** — автозапуск, ИИ-приложение, браузер для ссылок, видимые вкладки
- **Погода** и **Discord**
- **О Lumen** — проверка обновлений; о новой версии остров скажет сам

## Установка

Скачай `Lumen_x.y.z_x64-setup.exe` со [страницы релизов](https://github.com/Mittikbb/lumen/releases/latest)
и запусти. Права администратора не нужны. После установки Lumen запускается вместе с Windows;
в меню иконки в трее есть настройки, автозапуск и «Выход».

> Alt+Space по умолчанию занят PowerToys Run, если он установлен. Отключи его
> в настройках PowerToys, и Lumen подхватит сочетание сам, или назначь поиску
> другое сочетание в настройках Lumen.

### Подключение Discord

Discord пускает к звонкам только через собственное приложение, поэтому его нужно создать один раз:

1. Открой [Discord Developer Portal](https://discord.com/developers/applications) → **New Application**.
2. **OAuth2** → **Redirects**: добавь ровно один адрес `http://127.0.0.1` и нажми **Save Changes**.
   Там же **Reset Secret** — скопируй секрет.
3. Скопируй **Application ID** со страницы General Information.
4. В Lumen: Настройки → Discord, вставь ID и секрет, включи подключение
   и подтверди доступ в окне Discord.

Секрет хранится только на твоём компьютере. Если Discord у тебя работает через прокси,
Lumen использует тот же системный прокси Windows.

## Стек

[Tauri 2](https://tauri.app) (Rust) + React + TypeScript + [Motion](https://motion.dev).

## Разработка

Нужны [Node.js](https://nodejs.org), [Rust](https://rustup.rs) и Visual Studio Build Tools
с компонентом «Разработка классических приложений на C++».

```bash
npm install
npm run tauri dev
```

Сборка установщика (появится в `src-tauri/target/release/bundle/nsis/`):

```bash
npm run tauri build
```

Только интерфейс в браузере (без Rust): `npm run dev` и открыть http://localhost:1420
(окно настроек — http://localhost:1420/?settings).
